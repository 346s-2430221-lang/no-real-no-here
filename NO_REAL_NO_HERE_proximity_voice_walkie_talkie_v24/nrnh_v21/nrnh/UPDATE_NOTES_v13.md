# v13 업데이트 — 엔티티 경로 탐색 및 잠입 개선

- 엔티티 AI에 격자 기반 BFS 경로 탐색을 추가했습니다. 통로를 따라 플레이어에게 접근하며, 막히면 경로를 다시 계산합니다.
- 경로 갱신은 약 0.32초 간격으로 제한해 CPU 부담을 줄였습니다.
- 웅크리기 소음 계수를 낮춰, 시야 밖에서는 엔티티의 청각 감지 범위를 줄입니다. 시야에 보이면 발견될 수 있습니다.
- `Player.run`을 실제 입력/스태미나 조건과 동기화해 달리기 소음 판정을 개선했습니다.

## 자동 검증
- 모든 `src/*.js`, `shared/levels.js`, `server/server.js`에 `node --check` 통과
- BFS가 장애물 주변의 통로를 찾아가는 단위 테스트 통과
- 레벨 데이터 기본 검사 통과
- ZIP 무결성 검사 통과
