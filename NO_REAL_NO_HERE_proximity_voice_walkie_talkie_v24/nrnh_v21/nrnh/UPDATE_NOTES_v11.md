# NO REAL NO HERE — v11 업데이트

- 달리기 중 점프하면 점프 높이와 공중 이동 가속이 증가합니다. PC는 Space, 모바일은 점프 버튼.
- 글리치 상점에 팀원 순간이동기(랜덤 팀원), 팀원 나침반(가장 가까운 팀원의 방향/거리), 부활 십자가(충전형)를 추가했습니다.
- PC에서 X 또는 모바일 십자가 버튼으로 십자가를 사용합니다.
- 십자가 충전은 저장 데이터에 기록되며 다음 레벨로 이동해도 유지됩니다.
- 멀티플레이 서버에 팀원 순간이동 및 부활/재배치 메시지를 추가했습니다.
- JavaScript 구문 검사 통과, ZIP 무결성 검사 통과.
- 실제 브라우저/다중 기기 플레이 테스트는 수행하지 않았습니다. 현재 십자가는 선택한 팀원을 시작 지점으로 재배치하는 방식이며, 별도의 다운/사망 상태 시스템과는 아직 연결되어 있지 않습니다.
