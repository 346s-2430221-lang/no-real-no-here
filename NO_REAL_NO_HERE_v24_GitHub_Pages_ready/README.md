# NO REAL NO HERE (1인칭 3D 백룸 심리 공포 게임) — 진행 중인 개발 스냅샷

Three.js(r128) 기반 웹 게임. PC 브라우저와 안드로이드 태블릿 브라우저 대상.
**이 ZIP은 7단계 작업 도중의 스냅샷입니다.** 아래 "구현 상태"를 꼭 읽어 주세요.

## 실행 방법
1. ZIP을 풀고 `index.html`을 브라우저(Chrome 권장)로 엽니다. (안 되면 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000`)
2. **Three.js를 CDN(cdnjs)에서 불러오므로 인터넷 연결이 필요합니다.** 실패하면 동봉된 `libs/three.min.js`로 대체 로딩하도록 했지만, 이 대체 로딩은 실제 브라우저에서 검증하지 못했으므로 오프라인 실행을 보장하지 않습니다.
3. 안드로이드 태블릿: 같은 Wi-Fi의 PC에서 위 서버를 실행하고 `http://PC의IP:8000`으로 접속하거나, 폴더째 웹 호스팅(GitHub Pages 등)에 올려 접속합니다. 모든 경로는 상대 경로입니다. `.nojekyll` 파일을 포함했습니다.

## 조작
PC: WASD 이동 · 마우스 시점 · Shift 달리기 · C 웅크리기 · E 상호작용 · Tab 메모 · Esc 일시정지
모바일: 왼쪽 조이스틱 이동 · 오른쪽 드래그 시점 · 달리기/웅크리기/조사/메모 버튼 · ⏸ 일시정지

## 멀티플레이 서버
서버 코드는 `server/`에 분리되어 있습니다(클라이언트와 `shared/levels.js`만 공유).
```
cd server && npm install && node server.js      # 기본 포트 8080 (PORT 환경변수로 변경)
```
- 같은 서버가 게임 파일도 서빙하므로, 브라우저에서 `http://서버주소:8080`으로 접속하면 서버 주소가 자동 입력됩니다.
- GitHub Pages 같은 정적 호스팅은 **클라이언트만** 제공합니다. 서버는 별도 호스팅(VPS, Render, Fly.io 등)이 필요하며 HTTPS 페이지에서는 `wss://` 주소를 써야 합니다. 서버 주소는 멀티플레이 메뉴에서 입력하며 브라우저에 저장됩니다.
- 방 상태는 서버 메모리에만 있습니다(서버를 재시작하면 사라짐). 서버 측 영구 저장과 코인/구매 검증은 아직 없습니다.
- 서버가 없으면 싱글플레이는 그대로 동작합니다. 서버 연결을 테스트하지 않은 환경에서는 온라인 동기화가 되는 것처럼 동작하지 않습니다.

## 저장 데이터 안내
진행 상황은 이 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터 삭제, 다른 브라우저·기기 사용 시 사라질 수 있으니 슬롯 화면의 '내보내기'로 백업하세요.

## 검증 상태
- 검증함(Node 시뮬레이션): 문법, 저장 슬롯 전체, 퍼즐/문/출구/레벨 전환, 특별 레벨 진입 조건과 이동, 충돌, 맵 도달 가능성, 멀티플레이 서버(실제 WebSocket 다중 클라이언트)와 클라이언트 코드.
- **미검증(실제 브라우저/기기 필요):** 화면 렌더링과 그래픽, 마우스 고정, 터치 조작, 소리, 화면 회전, 모바일 성능, 파일 내보내기/가져오기 대화상자, CDN 대체 로딩, GitHub Pages 배포.

## 최근 작업: 그래픽 및 멀티플레이 채팅
- 렌더링에 sRGB 출력, ACES 톤 매핑, 색상 보정용 헤미스피어 조명, 더 깊은 거리 안개와 화면 비네트를 적용했습니다.
- 벽지/카펫 텍스처의 얼룩과 미세한 표면 흔적을 늘렸습니다. 기기 성능이 낮으면 설정에서 그래픽 품질을 낮추세요.
- 멀티플레이 HUD의 `채팅` 버튼으로 텍스트 채팅을 열 수 있습니다.
- `음성 켜기`는 WebRTC 음성 연결을 사용합니다. 마이크 권한이 필요하며, 배포 서버는 HTTPS/WSS여야 합니다. NAT/네트워크에 따라 STUN만으로 연결되지 않는 환경이 있을 수 있습니다. 운영 배포 수준의 안정성을 위해서는 TURN 서버가 추가로 필요합니다.
- WebRTC 시그널링 개선: 음성 시작 알림, ICE 후보 큐잉(원격 설명보다 후보가 먼저 도착하는 문제 완화), 연결 상태 표시, 연결 실패 시 ICE 재시도를 추가했습니다.
- `src/ice-config.js`에서 ICE 서버를 설정합니다. 기본값은 공개 STUN만 포함하므로 일부 NAT/통신사 네트워크에서는 여전히 연결이 실패할 수 있습니다. **거의 모든 네트워크에서 안정적으로 음성을 보장하려면 운영자가 관리하는 TURN 서버와 유효한 자격 증명이 필수**입니다. TURN 주소/사용자명/비밀번호를 설정 파일에 넣으면 공개 저장소에 비밀 정보가 노출될 수 있으므로, 공개 배포에는 만료되는 임시 자격 증명을 서버에서 발급하는 방식으로 바꾸세요.
- 음성 채팅은 실제 두 개 이상의 브라우저/기기와 마이크로 확인해야 합니다. 이 작업 환경에서는 실기기 마이크/외부 서버 연결 테스트를 완료했다고 주장하지 않습니다.
