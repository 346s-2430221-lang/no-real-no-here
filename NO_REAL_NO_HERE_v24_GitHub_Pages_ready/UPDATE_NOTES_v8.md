
# NO REAL NO HERE — Entity AI update v9

## 엔티티별 AI 프로필
- 기본 추격형: 시야/청각 감지, 마지막 목격 위치 수색, 배회와 추격 상태를 전환합니다.
- 붉은 복도/거울/시계 계열: 시야에 플레이어가 잡히면 재사용 대기시간을 두고 가까운 위치로 순간이동해 매복합니다.
- Poolrooms/침수 계열: 이동은 느리지만 더 오래 마지막 목격 위치를 수색하고 가까이 다가옵니다.
- 학교/병원/도서관/기록 보관소 계열: 넓은 범위를 순찰하고 소리에 민감하며 수색을 오래 유지합니다.
- Blackout/서버실/벙커 계열: 시야는 짧지만 청각 범위가 넓고 달리는 플레이어를 더 빠르게 추격합니다.
- 숲/교외/대피소 계열: 가까운 거리에서 물러나다가 다시 수색하는 회피형 행동을 합니다.
- Funhouse/Smiler/Party 계열: 플레이어가 일정 거리 안으로 접근하면 매복 상태로 전환합니다.

## AI 동작
- 배회, 감지, 추격, 마지막 목격 위치 수색, 매복/회피 상태를 사용합니다.
- 이동할 때 벽 충돌을 검사합니다. 엔티티가 플레이어를 붙잡으면 해당 레벨 시작점으로 돌려보내고 프로필별 메시지와 피해를 적용합니다.
- 각 프로필의 시야, 청각, 이동 속도, 수색 시간, 공격 피해가 달라집니다.

## 확인
- 모든 JavaScript 파일 구문 검사 및 ZIP 무결성 검사를 실행합니다.
- 브라우저에서 실제 플레이하며 AI를 장시간 관찰하는 테스트는 아직 하지 않았습니다. 맵별 길찾기는 간단한 벽 충돌 이동 방식이라 복잡한 막다른 길에서 끼일 수 있습니다.
