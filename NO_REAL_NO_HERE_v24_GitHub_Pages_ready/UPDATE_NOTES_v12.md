# v12 업데이트 — 음성 설정과 출시 전 정리

- 설정 메뉴에 음성 채팅 전용 옵션 추가: 팀원 음량, 마이크 음소거, 항상 송신/눌러서 말하기.
- 눌러서 말하기는 PC `V` 키와 모바일 화면 버튼을 지원하며, 창이 숨겨지거나 포커스를 잃으면 송신 상태를 해제합니다.
- 옵션 변경 시 활성 음성 트랙과 기존 상대 오디오 음량에 즉시 반영됩니다.
- README에 배포 요구 사항 및 미완료/미검증 항목을 분명하게 기록했습니다.

## 검증
- Node.js 구문 검사: src JS 전체와 서버 파일.
- ZIP 무결성 검사.
- 브라우저의 실제 마이크, 외부 네트워크의 WebRTC, 모바일 터치 및 멀티플레이 실기기 검증은 수행하지 않았습니다.
