# 별빛 숲 RPG ✦

브라우저에서 바로 플레이할 수 있는 작은 한국어 픽셀 아트 RPG입니다. 별도 설치나 빌드 도구가 필요하지 않습니다.

## 플레이하기
GitHub Pages가 켜져 있다면:
- https://346s-2430221-lang.github.io/no-real-no-here/pixel-rpg/

## 조작
- 이동: WASD 또는 방향키
- 공격: Space
- 보물상자 열기: E
- 포션 사용: 화면의 포션 버튼
- 모바일/태블릿: 화면 아래 방향 버튼과 공격/줍기 버튼

## 포함된 기능
- 픽셀 스타일 숲 맵과 장애물
- 플레이어 이동 및 근접 공격
- 플레이어를 추적하는 슬라임 몬스터
- HP, 경험치, 레벨 업, 골드
- 슬라임 처치 의뢰와 보물상자
- 회복 포션
- 브라우저 로컬 저장
- 모바일 터치 조작

## 실행 방법
1. `pixel-rpg/index.html`을 브라우저에서 열거나 GitHub Pages 주소로 접속합니다.
2. 게임 화면을 누르고 플레이하세요.
3. 진행 상황은 **저장** 버튼을 눌러 현재 기기의 브라우저에 저장할 수 있습니다.

이 프로젝트는 정적 HTML/CSS/JavaScript로 만들어져 서버나 패키지 설치가 필요 없습니다.
