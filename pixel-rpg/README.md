# 별빛 숲 RPG ✦ 확장판

설치 없이 브라우저에서 실행되는 한국어 픽셀 RPG입니다.

## 플레이
GitHub Pages가 활성화되어 있다면:
https://346s-2430221-lang.github.io/no-real-no-here/pixel-rpg/

## 조작
- 이동: WASD 또는 방향키
- 공격: Space
- 상자 열기 / 상호작용: E 또는 화면의 상호작용 버튼
- 포션: 포션 버튼
- 모바일/태블릿: 화면 아래 방향 버튼과 공격/줍기 버튼

## 기능
- 픽셀 스타일 마을, 별빛 숲, 어둠의 던전
- 몬스터 AI: 플레이어를 발견하면 추적하고 접촉 시 공격
- 슬라임, 박쥐, 해골 전사, 보스 몬스터
- 보스 전투와 추가 보상
- 마을 상점: 포션, 철검, 별빛 검, 용기사 검, 가죽/철/별빛 갑옷
- 장비에 따른 공격력과 방어력
- HP, 경험치, 레벨 업 및 레벨 업 회복
- 몬스터 처치 의뢰와 골드 보상
- 던전 보물상자
- 저장 및 불러오기 (현재 브라우저의 로컬 저장소)
- PC 키보드 및 모바일/태블릿 터치 조작

## 실행
1. `pixel-rpg/index.html`을 브라우저에서 열거나 위 GitHub Pages 주소에 접속합니다.
2. 마을 상점에서 장비를 사고 포션을 준비합니다.
3. 어둠의 던전에 들어가 몬스터와 보스를 처치하세요.
4. 진행 상황은 저장 버튼으로 저장할 수 있습니다.

정적 HTML/CSS/JavaScript 프로젝트라 별도 서버나 패키지 설치가 필요하지 않습니다.
