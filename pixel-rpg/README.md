# 별빛 숲 RPG ✦ 확장판

설치 없이 브라우저에서 실행되는 한국어 픽셀 RPG입니다.

## 플레이
GitHub Pages가 활성화되어 있다면:
https://346s-2430221-lang.github.io/no-real-no-here/pixel-rpg/

## 조작
- 이동: WASD 또는 방향키
- 공격: Space
- 상자 열기 / 상호작용: E 또는 화면의 상호작용 버튼
- 포션: 포션 버튼
- 모바일/태블릿: 화면 아래 방향 버튼과 공격/줍기 버튼

## 기능
- 픽셀 스타일 마을, 별빛 숲, 어둠의 던전, 수정 광산
- 지역 이동 시 회전하는 차원 포탈 효과와 E 상호작용 포탈
- 캐릭터 명암/하이라이트 도트와 더 읽기 쉬운 UI 글자 크기/버튼 대비
- 몬스터 AI: 플레이어를 발견하면 추적하고 접촉 시 공격
- 슬라임, 박쥐, 해골 전사, 보스 몬스터
- 보스 전투와 추가 보상
- 마을 상점: 포션, 철검, 별빛 검, 용기사 검, 가죽/철/별빛 갑옷, 바닥·벽·꾸미기 블록·회로 장치 구매
- 블록/회로 장치는 초기 보유량이 있으며 설치할 때 재고를 소비하고, 상점에서 추가 구매 가능
- 픽셀 그래픽 보강: 지형 타일의 밝은 가장자리, 돌/풀/광물 하이라이트, 캐릭터 장비 명암과 윤곽 디테일
- 장비에 따른 공격력과 방어력
- HP, 경험치, 레벨 업 및 레벨 업 회복
- 몬스터 처치 의뢰와 골드 보상
- 던전 보물상자
- 저장 및 불러오기 (현재 브라우저의 로컬 저장소)
- PC 키보드 및 모바일/태블릿 터치 조작
- Render WebSocket 서버를 이용한 온라인 멀티플레이: 최대 24명 접속, 비공개 방 코드 초대, 공개 서버 생성 및 공개 서버 목록에서 참가, 실시간 캐릭터 위치 동기화
- 온라인 방에서 몬스터 체력, 처치 상태, 보물 상자 개방 상태 동기화
- 온라인 플레이어 목록과 각 플레이어의 현재 지역 표시
- 서버가 보물 상자 개방을 확인한 뒤 보상 지급 (중복 열기 방지)
- 친구와 실시간 채팅
- 농장 지역: 씨앗 심기, 물 주기, 60초 하루 주기, 작물 성장과 수확 보상
- 타일 기반 건축: 바닥, 벽, 철거 도구와 최대 300개 장치 배치
- 농장 꾸미기: 꽃, 울타리, 벤치, 정원등, 작은 연못 배치
- 광산 채굴: 곡괭이로 돌, 구리, 철광석, 마력 수정을 캐고 광물 수량 확인
- 회로 블록: 전선, 발전기, 레버, 버튼, 압력판, 레드스톤 횃불, 리피터, 비교기, 관측기
- 작동 장치: 전등, 문, 다락문, 피스톤, 끈끈이 피스톤, 음 블록, 발사기, 공급기, 호퍼, TNT
- AND/OR/NOT/XOR 논리 게이트와 시계/햇빛 센서
- 회로 타이머, 기본 신호 전달, 압력판 감지, 관측기 변화 감지, 피스톤/끈끈이 피스톤의 단순 블록 밀기·당기기
- TNT의 주변 장치 파괴, 발사기/공급기 작동 표시, 온라인 방에서 회로 배치와 순간 신호 동기화
- 주의: 마인크래프트의 완전한 레드스톤 엔진과 동일하지 않으며, 비교기·발사기·호퍼 등 일부 동작은 간략화된 시뮬레이션
- 온라인 방에서 농장 작물과 건축/회로 상태 동기화 (방이 유지되는 동안 공유)

## 실행
1. `pixel-rpg/index.html`을 브라우저에서 열거나 위 GitHub Pages 주소에 접속합니다.
2. 마을 상점에서 장비를 사고 포션을 준비합니다.
3. 어둠의 던전에 들어가 몬스터와 보스를 처치하세요.
4. 진행 상황은 저장 버튼으로 저장할 수 있습니다.

싱글플레이는 정적 HTML/CSS/JavaScript로 실행됩니다. 온라인 멀티플레이는 Render의 `wss://no-real-no-here.onrender.com` 서버에 연결됩니다. 비공개 방은 6자리 코드를 공유해 입장하고, 공개 서버는 공개 서버 목록에 표시되어 누구나 참가할 수 있습니다. 서버당 최대 24명이며, 같은 지역에서 캐릭터와 몬스터 전투 상태를 함께 확인할 수 있습니다. Render 서비스가 잠들어 있으면 첫 연결에 시간이 걸릴 수 있습니다.


## 월드 확장 / 그래픽 개선
- 각 지역을 기존 20×13 타일에서 40×26 타일 월드로 확장하고 플레이어를 따라가는 카메라를 적용했습니다.
- 숲·던전의 몬스터와 보물상자를 넓은 지역에 분산 배치했습니다.
- 타일 하이라이트, 환경 디테일, 캐릭터/몬스터/상자의 그림자를 추가해 도트 그래픽의 깊이를 보강했습니다.
- 현재는 타일 기반 2D 월드이며, 실제 플레이 중 브라우저와 Render 멀티플레이 실측 테스트는 별도로 필요합니다.


## 최근 업데이트
- 인벤토리 창 추가: 포션, 골드, 씨앗, 광물, 장착 장비, 건축/회로 블록 보유량 확인.
- 포탈 오브젝트 및 접촉 이동 제거. 지역 버튼으로 바로 이동.
- 전투 피격 시 몬스터 섬광과 파편 효과, 플레이어 피격 깜빡임, 몬스터 공격 예고선 및 동굴 음영 추가.
- JavaScript 문법 검사 통과. 실제 브라우저·멀티플레이 플레이 테스트는 별도로 필요.


## 월드 확장 업데이트
- 월드 크기: 40×26 타일에서 60×40 타일로 확장(총 타일 수 4배).
- 신규 지역 3곳: 서리바람 설원, 황금모래 사막, 안개늪지.
- 각 신규 지역은 고유한 바닥 팔레트와 환경 장식, 장애물, 몬스터, 보물 상자를 가짐.
- 숲과 던전의 몬스터·보물 상자 배치를 더 넓은 영역으로 확장.
- Render 멀티플레이 서버의 지역 허용 목록과 좌표 제한을 확장 월드에 맞게 수정.
- 클라이언트와 서버 JavaScript 문법 검사 통과. 실제 온라인 런타임 테스트는 별도로 필요.
